# NexaTech AI-Powered Customer Growth Platform

## Selected Track
AI Growth & Agentic Commerce

## What was added
- Nexa AI Growth Assistant floating chat interface.
- Customer requirement understanding using a lightweight intent-matching recommendation layer.
- Service recommendations for Web Development, Mobile Development, Cloud Solutions, Artificial Intelligence, UI/UX Design and Digital Marketing.
- Direct links from recommendations to the relevant service pages.
- Lead capture for name, email and company.
- Lead records are stored locally in the browser under `nexatech_ai_leads` for the prototype/demo.

## Run
```bash
npm install
npm run dev
```

## Important
This ZIP is a frontend prototype. The assistant's recommendation layer is intentionally dependency-free so the project runs without an external AI API key. For a production version, the recommendation layer can be replaced with a server-side LLM/agent API and the lead storage can be connected to a real database/CRM.
