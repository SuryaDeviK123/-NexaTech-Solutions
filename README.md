# 🚀 NexaTech Solutions

A modern, responsive, and professional corporate website built for **NexaTech Solutions**. The website showcases the company's services, projects, career opportunities, and AI-powered business assistance through a clean and premium user interface.

## 🌐 About the Project

NexaTech Solutions is a corporate technology website designed to present digital solutions and services in a professional way.

The website focuses on:

- Modern corporate design
- Responsive layout
- Smooth page transitions
- Interactive components
- Dark/Light theme support
- AI Growth Assistant
- Services and project showcases
- Career and job application pages
- Contact and newsletter sections

### 🏠 Home
